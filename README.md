# 持仓助手 · VOO / 伯克希尔B / AAPL / 拼多多

一个跑在这台电脑上、iPhone Safari 能打开的小应用：**录入现有持仓**、按比例算该买多少、一键买入并入账、随时看持仓比重和收益。

跟踪四只标的：**VOO**、**伯克希尔 B（BRK.B）**、**苹果（AAPL）**、**拼多多（PDD）**。

**零依赖**——只用 Node 内置模块，不需要 `npm install`，不向任何第三方上传你的持仓数据。

## 2. 三种用手机打开的方式（挑一种）

| 方式 | 需要什么 | 费用 | 电脑能关机吗 | 看哪一节 |
|---|---|---|---|---|
| **A. 局域网** | 手机和电脑同一个 WiFi | 免费 | ❌ 不能 | 下面 A |
| **B. Tailscale 私有网** | 电脑手机各装一次 Tailscale | 免费 | ❌ 不能（服务在电脑上） | 下面 B |
| **C. 部署到云端** | 两个免费账号（键值存储 + 容器） | 免费 | ✅ **能关机** | [DEPLOY.md](DEPLOY.md) |

> 关键区别：A 和 B 只是「怎么连到这台电脑」，服务器和数据始终在这台电脑上，所以**电脑必须开着**。
> 只有 C 把「页面」和「数据」都搬到云上，电脑才能随便关。
> **C 用的是免费档 + 免费键值存储**：因为免费容器档没有持久磁盘，所以数据存在你自己的免费键值存储里，容器保持无状态。

### A. 局域网（同 WiFi）

1. 双击 `start.bat`，看窗口里打印的局域网地址（形如 `http://192.168.2.28:8787`）和口令
2. iPhone 用 **Safari** 打开这个地址 → 填口令 → 分享 → **添加到主屏幕**

### B. Tailscale（在别的 WiFi / 用流量时）

Tailscale 给手机和电脑组一个私有网络，并自动签发 **HTTPS 证书**，所以不需要买域名、不需要备案、也不会被公网扫到。

1. **电脑装**：`winget install -e --id Tailscale.Tailscale` → 打开 Tailscale → 登录
2. **iPhone 装**：App Store 搜 Tailscale → 登录**同一个账号**
3. **管理台开两个开关**（只做一次）：[login.tailscale.com/admin/dns](https://login.tailscale.com/admin/dns) → 打开 **MagicDNS** 和 **HTTPS Certificates**
4. **电脑上把 HTTPS 转给本应用**（管理员 PowerShell，跑一次就够）：
   ```powershell
   tailscale serve --bg 8787
   tailscale serve status          # 复查，应显示 https://<机器名>.<tailnet>.ts.net
   ```
5. **iPhone** 打开那个 `https://...ts.net` → 分享 → **添加到主屏幕**

这条路径**不需要口令**（Tailscale 自己做了身份验证）。退路：`tailscale ip -4` 拿到 `100.x` 地址后直接访问 `http://100.x:8787`。

**电脑别睡**：设置 → 系统 → 电源 → 「接通电源时进入睡眠」设为「从不」。（你机器当前已经是「从不」，无需改。）

### C. 云端部署（关机也能用，免费）

见 **[DEPLOY.md](DEPLOY.md)**。要点：

- 数据存到你自己的**免费键值存储**（Upstash，免费档每月几十万次命令，够用），容器完全无状态 → 免费档重启/休眠都不丢数据
- 页面顶栏会显示数据存在哪：**云同步** / **本机文件** / **云存储异常 · 只读**
- 云存储临时不可用时**会自动变成只读**并明确警告，**拒绝写入**而不是静默丢数据
- 两步注册需要你本人操作；命令我可以代跑

## 3. 页面结构

从上到下：

| 区域 | 干什么 |
|---|---|
| 行情条 | 四只标的的现价、涨跌、昨收、行情时间 |
| **① 我的持仓** | 顶部四个大数字（总市值 / 当日盈亏 / 累计浮动盈亏 / 累计投入）+ 环形图比重 + 每只的**份额与成本价输入框**，右侧就近显示 现价 / 市值 / 当日盈亏 / 累计盈亏 / 比重。底部「保存持仓」「全部清零」「重置当日基准」，行尾「收起明细」只收起表格、**大数字和环形图始终可见** |
| ② 按比例买入 | 填总金额 + 各标的占比，实时算出每只的买入金额、股数、手续费、实际扣款；可以单只买，也可以「按配比全部买入」 |
| 买入流水 | 每笔的时间、股数、成交价、手续费、扣款、买入后的含费成本价 |

**填持仓不用先保存就能看结果**：在①里改份额或成本价，市值、当日盈亏、累计盈亏、比重、顶部四个大数字和环形图会立刻重算，并在底部提示「有 N 只改动尚未保存」。点「保存持仓」才写进 `state.json`。

**一键买入后会自动同步**：买入的份额与含费成本价直接并进①的输入框，大数字与环形图同步刷新，流水多一条，并且可以点「撤销」精确回滚。

改配比会自动保存；「均分」按标的数量自动算（现在是 25% 一份）；「恢复上次」把配比退回上次保存的值；**「补齐到 100%」** 会把当前差额一键加到 PDD 上（差额会是负数、或加完超过 100% 时它会拒绝并提示手动改）。

**改百分比不会让表格消失**：以前版本在百分比之和 ≠ 100 时会重建表格却算出空内容，导致输入框一起消失、永远凑不到 100%。现在：

- 表格结构只建一次，之后**只就地更新数字**，绝不重建输入框（也不会丢焦点和光标）；
- 和不等于 100 时表格照常显示，表尾出现红色角标「还差 / 超出 X.XX%」，提示行告诉你怎么补；
- 这个 bug 有专门的自动化回归测试盯着（`test/smoke.mjs` 里的「前端：配比区在百分比不合法时不能清空表格」）。

**百分比只收整数，输入过程不会跳变**：

| 你输入 | 实际生效 |
|---|---|
| `45` | 45 |
| `4.5` | 4（小数点之后的内容丢掉） |
| `999` | 100（夹到上限） |
| `-10` | 10（负号丢掉） |
| `abc` | 空（非数字清空） |
| `007` | 7（去掉前导零） |

**忘记配平也不用管**：离开输入框时，如果加起来不是 100%，会自动把差额补到「除你刚改的那只以外、当前最大的一只」上，并给出提示；补不动（会变成负数或超过 100%）就不动、也不保存，等你手动改。另外「补齐到 100%」按钮会把差额直接加到 PDD 上。

不合法时**不会写进 `state.json`**（配比之和 ≠ 100、总金额 ≤ 0、费率超范围都会被拦住），所以不会出现「下次打开总金额变成莫名其妙的小数字」。

## 4. 它怎么算的（口径都在这里，可核对）

### 买入规则

| 项 | 规则 |
|---|---|
| 最小交易单位 | **0.01 股**，而且**向下取整**（不会超出你给的金额） |
| 手续费 | **买入金额 × 费率**，默认 **0.1%**，页面上的「手续费 %」可以随时改 |
| 手续费口径 | **另计**：你填的金额是「买入多少钱的股票」，手续费额外扣 |
| 成本价 | **含手续费**摊进成本，所以「累计盈亏」是你真实到手的盈亏 |

每只标的：

```
股数        = floor(买入金额 ÷ 现价 ÷ 0.01) × 0.01
股票占用    = 股数 × 现价
手续费      = 买入金额 × 费率
实际扣款    = 股票占用 + 手续费
未用余额    = 买入金额 − 股票占用        ← 0.01 股取整留下的零头
新成本价    = (原份额×原成本价 + 股票占用 + 手续费) ÷ (原份额 + 新份额)
```

**实例**（总金额 $3000、VOO 55 / BRK.B 25 / AAPL 12 / PDD 8、费率 0.1%、2026-10-12 的真实盘面价）：

| 标的 | 现价 | 买入金额 | 股数 | 股票占用 | 手续费 | 实际扣款 | 未用余额 |
|---|---|---|---|---|---|---|---|
| VOO | 715.59 | 1650 | 2.30 | 1645.86 | 1.65 | **1647.51** | 4.14 |
| BRK.B | 515.62 | 750 | 1.45 | 747.65 | 0.75 | **748.40** | 2.35 |
| AAPL | 336.64 | 360 | 1.06 | 356.84 | 0.36 | **357.20** | 3.16 |
| PDD | 81.35 | 240 | 2.95 | 239.98 | 0.24 | **240.22** | 0.02 |
| **合计** | | 3000 | | 2990.33 | 3.00 | **2993.33** | 9.67 |

注意：**实际扣款不会超过你填的金额 + 手续费**（这里是 2993.33 ≤ 3003.00），差额来自 0.01 股取整的零头，页面会把它显示成「未用余额」。

### 收益口径

- **当日盈亏** = `(现价 − 昨收) × 份额`。休市时现价就是上次收盘价，所以当日盈亏为 0，页面会明确标「休市 / 最近收盘 <日期>」。
- **累计浮动盈亏** = `市值 − 份额 × 含费成本价`。刚买完一定是负的，负的那部分正好等于手续费，这是对的。
- **持仓比重** = `该只市值 ÷ 全部标的市值合计`（环形图 + 百分比，合计恒为 100%）。
- ②里录入的份额与成本价会和一键买入累加在同一份数据上：买入后成本价按含费加权自动更新。
- 跨交易日时会自动把「当日基准」滚到最新的昨收（避免把前一天的涨跌重复算进今天），也可以在页面上手动「重置当日基准」。

## 5. 行情从哪来

- 主源：腾讯行情 `qt.gtimg.cn`（GBK 编码，服务端代理并转成 UTF-8，不依赖浏览器跨域）
- 备源：新浪行情 `hq.sinajs.cn`，**只用来补腾讯拿不到的标的**（新浪上 `BRK.B` 恒为空，实测过）
- 服务端缓存 10 秒；页面每 30 秒自动刷一次，回到前台也会立刻刷一次
- 某只拿不到价格时会保留上一次成功价格并标「旧价」，**绝不会把缺价格当成 0**；此时该只不允许下单

这几条免费接口不需要任何 API Key。它们都是延时行情（非交易所直连），不适合做日内高频决策；用来做定投配比和看持仓足够。

## 6. 备份、恢复与安全

- **你的数据只有一个文件**：`state.json`（在 `stock/` 目录下）。复制这个文件就是完整备份；把它覆盖回来就是恢复。
- **口令**存在 `.auth.txt`。想换口令：删掉这个文件再重启，会生成新的。
- `state.json`、`.auth.txt` 都写进了 `.gitignore`，不会被提交到任何仓库。
- **访问控制**：来自本机、Tailscale 网段（`100.64.0.0/10`）的访问免口令；来自局域网、且走明文 HTTP 的访问必须输入口令。所以同一 WiFi 下别人扫不到你的持仓。
- 想彻底关掉口令（比如只在本机用）：启动前设环境变量 `STOCK_AUTH=off`。
- 想换端口：`set PORT=9000 && node server.mjs`（Windows 命令提示符）。

## 7. 什么时候会看到什么

| 现象 | 说明 |
|---|---|
| 顶栏写「休市 / 最近收盘 …」 | 美股非交易时段（含周末和假日）。当日盈亏显示为 0 是正确的，不是 bug |
| 某只标着「旧价」角标 | 上游暂时没返回，显示的是上次成功价格，会写明时间 |
| 某只标着「备用源」角标 | 这只走的是新浪行情而不是腾讯 |
| 「不足 0.01 股，该只最少 $X」 | 该只分到的金额连最小单位都买不到，加大金额或调整比例 |
| 「4 个百分比之和是 …，必须等于 100%」 | 配比没配平。表格不会消失，表尾会显示「还差 / 超出 X.XX%」，可以手改或点「补齐到 100%」 |
| 百分比输入框突然没了 | 早期版本的 bug（不合法时清空了表格），已修并有回归测试；如果还遇到请刷新页面（Ctrl+F5） |
| 刚买完累计盈亏是负的 | 等于手续费，正常 |
| ①里改了数字但收益没变 | 数字会立刻变（不用保存）；只有写进文件才需要点「保存持仓」 |
| 点保存/买入没反应 | 早先版本有这个问题，原因是 `state.json` 的写入竞态（并发写共用同一个临时文件，rename 报 ENOENT 导致接口 500）。已修：所有写都串行排队 + 每次写用独立临时文件，并有专门的并发回归测试 |
| iPhone 上点了没反应 | 电脑上的服务窗口被关了，或电脑睡眠了；重新启动服务 |
| 局域网打不开 | 确认两台设备在同一个 WiFi；Windows 防火墙三档实测是关闭的，若你后来打开了防火墙，需要放行 8787 端口 |

## 9. 动手改之前先知道的事

- **再加一只标的**：改 `lib/quotes.mjs` 与 `lib/quant.mjs` 里的 `SYMBOLS`（两处都要），并在 `SYMBOL_META` 里补上 `{ name, tencent, sina }` 三个字段；前端 `pub/index.html` 顶部的 `SYMBOLS` 也同步一下。其余逻辑（配比、持仓、行情、界面、测试里的循环）都是按 `SYMBOLS` 遍历的，不用改。默认配比在 `lib/store.mjs` 的 `DEFAULT_STATE`。
